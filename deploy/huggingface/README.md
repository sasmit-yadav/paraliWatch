# Parali Watch (live demo)

Next-3-day crop-residue fire risk for Punjab and Haryana on a map, with the reasons behind each
prediction, a district bulletin, and an assistant that answers questions about schemes from
official documents with page citations (English or Hindi).

This demo replays the 2025 season (the model's unseen test season). Source code, evaluation and
documentation: https://github.com/sasmit-yadav/paraliWatch
